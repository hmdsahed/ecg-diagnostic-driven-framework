# Experiment Configurations

This directory stores configuration files used to manage
reproducible ECG experiments.

## Planned Configurations

- Dataset and recording settings
- ECG preprocessing parameters
- Heartbeat segmentation settings
- Feature extraction settings
- Model hyperparameters
- Training configurations
- Evaluation settings

## Reproducibility

Experimental configurations will be stored separately from
implementation code.

Changes to configurations will be tracked through Git version control.
