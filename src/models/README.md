# Machine Learning Models

This directory contains reusable implementations of machine learning,
deep learning, and hybrid models for ECG classification.

## Traditional Machine Learning
- Random Forest
- Support Vector Machine (SVM)
- XGBoost

## Deep Learning
- 1D Convolutional Neural Network (1D-CNN)
- Long Short-Term Memory (LSTM)

## Hybrid Models
- Feature-level fusion
- CNN-LSTM, subject to experimental feasibility

Model configurations, training procedures, and implementation details
will be documented for reproducibility.
