# Feature Extraction

This directory contains reusable functions for extracting numerical features from ECG signals.

Planned feature groups:

### Temporal Features
- Previous RR interval
- Following RR interval, where appropriate
- Local RR interval statistics

### Morphological Features
- QRS duration
- R-peak amplitude
- ECG waveform measurements

### Statistical Features
- Mean
- Standard deviation
- Variance
- Other justified signal descriptors

Feature definitions and extraction procedures will be documented for reproducibility.
