# Model Evaluation

This directory contains reusable functions for evaluating ECG
classification models and comparing experimental results.

## Classification Metrics
- Accuracy
- Balanced accuracy
- Macro F1-score
- Per-class precision and recall
- Confusion matrix

## Statistical Comparison
- Paired model comparisons
- Confidence intervals
- Effect-size estimation
- Multiple-comparison correction, where appropriate

## Robustness Analysis
- Performance across subjects
- Performance across heartbeat classes
- Sensitivity analysis
- Model comparison under different recording conditions

All evaluation procedures will follow the predefined experimental
protocol to ensure fair and reproducible comparisons.
