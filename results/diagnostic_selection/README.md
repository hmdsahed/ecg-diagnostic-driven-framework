# Diagnostic-Driven Model Selection Results

This directory stores experimental outputs from the proposed
diagnostic-driven model selection framework.

## Planned Outputs

- ECG diagnostic profiles
- Diagnostic feature summaries
- Model selection rules
- Selected modelling strategies
- Fixed-model versus diagnostic-driven comparisons
- Classification performance comparisons
- Robustness and sensitivity analysis

## Research Objective

Investigate whether statistical and signal-level characteristics
of ECG recordings can provide useful guidance for selecting
appropriate machine learning strategies.

All selection procedures will be developed without using
independent test-set labels or performance results.
