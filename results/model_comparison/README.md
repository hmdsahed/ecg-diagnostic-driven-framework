# Model Comparison Results

This directory stores experimental results from ECG heartbeat
classification models.

## Candidate Models

### Traditional Machine Learning
- Random Forest
- Support Vector Machine
- XGBoost

### Deep Learning
- 1D-CNN
- LSTM, subject to feasibility

### Hybrid Approaches
- Feature-level fusion
- CNN-LSTM, subject to feasibility

## Planned Outputs

- Classification metrics
- Per-class performance
- Confusion matrices
- Model comparison tables
- Performance visualizations

All comparisons will follow the predefined evaluation protocol.
