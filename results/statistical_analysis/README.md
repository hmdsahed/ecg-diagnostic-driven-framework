# Statistical Analysis Results

This directory stores outputs from the statistical analysis of the
MIT-BIH Arrhythmia Database.

## Planned Outputs

- Stationarity test results (ADF and KPSS)
- Rolling statistical feature summaries
- Spearman correlation analysis
- Mann–Whitney U test results
- Multiple-testing correction results (BH-FDR)
- Effect-size estimates
- Statistical analysis figures

All results will be generated from the research notebooks and
preserved for reproducibility.
